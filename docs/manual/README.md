# 📚 مستندات جامع — سامانه ارزیابی عملکرد کارکنان

> **یک‌خطی:** راهنمای کامل و آموزشی پروژه‌ای فارسی‌زبان، راست‌به‌چپ و سازمانی برای ارزیابی عملکرد کارکنان — از معرفی و نصب تا معماری، توسعه، استقرار و عیب‌یابی.

**نسخه سند:** ۰.۱.۰ · **وضعیت:** مطابق کد فعلی مخزن · **زبان:** فارسی (RTL)

---

## 🔎 خلاصه واقعیت‌های تأییدشده از کد (مبنای این مستند)

| شاخص | مقدار | منبع |
|---|---|---|
| مدل‌های داده (Prisma) | **۶۳** | `database/schema.prisma` |
| مهاجرت‌ها | **۳** | `database/migrations/` |
| دسترسی‌ها (Permission) | **۷۳** | `packages/shared/src/permissions.ts` |
| نقش‌های پیش‌فرض | **۵** | `packages/shared/src/roles.ts` |
| ماژول‌های API | **۱۹** | `apps/api/src/modules/` |
| صفحات وب (App Router) | **۳۴** | `apps/web/src/app/**/page.tsx` |
| کامپوننت‌های کلاینت | **۲۹** | `apps/web/src/components/*.tsx` |
| تست واحد | **۲۲** (۲ فایل) | `tests/unit/` |
| تست سرتاسری (E2E) | **۷۴** بررسی | `scripts/verify.cjs` |

> 💡 همه اعداد این سند با اجرای واقعی روی همین مخزن استخراج شده‌اند (نه از حافظه یا فرض).
